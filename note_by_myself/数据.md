## 二、math data

### 1.1、pretrain data

| Dataset          | Description                                                  | Url                                                        |
| ---------------- | ------------------------------------------------------------ | ---------------------------------------------------------- |
| Nemotron-CC-Math | 提供 **133B** 和 **52B** token 两个版本;从 Common Crawl 提取，采用布局感知渲染技术保留公式结构，质量在同类开源预训练数学语料中处于领先水平 | https://huggingface.co/datasets/nvidia/Nemotron-CC-Math-v1 |
| MegaMath         | **371B** token;整合了网页数据、高质量数学代码（来自 Stack-V2）以及合成的 QA 与代码数据，旨在同时覆盖数量与质量 | https://huggingface.co/datasets/IFM/MegaMath               |



### 1.2、sft data

| Dataset                      | Description                                                  | Url                                                          |
| ---------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| InfinityMATH                 | 超过 **10 万**条样本;基于 GSM8K、MATH 等数据集，通过程序化思维（PoT）方法合成，覆盖从小学到大学、代数到几何的多个层次 | https://huggingface.co/datasets/flagopen/InfinityMATH        |
| Nemotron-SFT-Math-v4         | 约 **54.5 万**条训练样本;NVIDIA 发布，包含思维链（CoT）和工具推理（TIR）两类数据，适合作为 SFT 阶段的高质量数据源 | https://huggingface.co/datasets/nvidia/Nemotron-SFT-Math-v4  |
| OpenR1-Math-15k-3072         | **1.5 万**条（经长度过滤）;从 OpenR1 系列数据中筛选而来，每条包含问题与长思维链（CoT）响应，专门适配 3072 token 上下文的小模型 SFT | https://huggingface.co/datasets/txie/OpenR1-Math-15k-3072    |
| Math SFT Solutions No CoT V4 | **约 144.6 万**条;特点在于**移除了中间推理步骤**，仅保留“指令→答案”的简洁监督格式，适合希望模型直接输出结果而非长推理链的场景 | https://huggingface.co/datasets/kaushik-harsh-99/math-sft-solutions-no-cot-v4 |



### 1.3、rl data

| Dataset                      | Description                                                  | Url                                                          |
| ---------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **Nemotron-RL-Math-v2**      | 精选数学问题集;NVIDIA 发布，问题来源包括 AoPS、StackExchange 等，所有答案均经过验证，专为可验证奖励的 RL 训练设计 | https://huggingface.co/datasets/nvidia/Nemotron-RL-Math-v2   |
| **mAceReason-Math**          | 14 种语言，每语言 **超 1 万**条;针对 RLVR 场景构建的多语言高难度数学问题集，弥补了现有 RL 数据以英语为主的不足 | https://github.com/apple-aiml-research/ml-macereason-math    |
| **Nemotron-Cascade-RL-Math** | **14,476** 道数学题;从 OpenMathReasoning、NuminaMath、DeepScaleR 等来源精选，经过数据去污染处理，专门用于数学推理 RL 训练 | https://huggingface.co/datasets/nvidia/Nemotron-Cascade-RL-Math |
| **daVinci-Math（RL 部分）**  | 多来源聚合;该数据集采用统一管线，将问题路由到 midtraining、SFT 或 RL 阶段，其 RL 部分聚合了 Skywork-OR1-RL、DAPO-Math-17k 等多个公开 RL 数据源 | https://huggingface.co/datasets/davincimath/davinci-math     |
